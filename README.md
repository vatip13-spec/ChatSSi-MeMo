# ChatSSi MeMo v2

SillyTavern에서 AI에게 전달되지 않는 개인 메모를 작성하는 확장입니다. v2부터 메모는 채팅 JSONL이 아닌 SillyTavern 사용자 파일에 저장되며, 같은 캐릭터의 일반 채팅·새 채팅·브랜치가 하나의 메모장을 자동으로 공유합니다.

## v2.0.1 저장 안정성 수정

- 저장 확인 뒤에도 편집 중인 메모 객체를 교체하지 않아 이후 입력이 끊기지 않음
- 창 닫기·검색·재정렬·채팅 전환 직전에 화면의 제목과 본문을 저장소로 다시 회수
- 저장 도중 발생한 새 입력은 별도 저장 세대로 감지해 자동으로 이어서 저장
- 한글 조합 종료 타이머를 화면 교체 전에 정리하고 현재 표시 내용을 우선 보존
- 수동 백업 직전에도 화면에 보이는 최신 입력을 강제로 반영

## v2.0.0 핵심 변경

- 같은 캐릭터 카드의 모든 채팅과 브랜치가 메모 공유
- 그룹 채팅은 그룹 ID별로 메모 공유
- 다른 캐릭터와 그룹의 메모는 분리
- 채팅 메타데이터 대신 `data/<사용자>/user/files`의 별도 파일 사용
- 기존 v1.x 메모는 원본을 지우지 않고 새 파일로 복사
- 기존 메모의 인라인 이미지는 개별 이미지 파일로 분리하고 SHA-256 검증
- 저장 전 직전 정상본을 `.previous.json`으로 보존
- 여러 탭·기기의 동시 덮어쓰기를 막는 편집권 잠금
- 현재 캐릭터·전체 메모 수동 백업, 내부 스냅샷, 검증 복원

메모 내용은 캐릭터 카드, 채팅 메시지, 프롬프트 또는 API 요청에 주입되지 않습니다.

## 주요 기능

- 여러 개의 스티키 메모 카드
- 카드별 자동 높이 및 수동 세로 크기 조절·저장
- 글·체크리스트·이미지를 섞는 연속 편집
- 체크 줄 Enter 연속 입력, 빈 줄 Enter 해제, 맨 앞 Backspace 해제
- 굵게·기울이기·밑줄·취소선 및 부분 글씨 크기
- 부분 형광펜과 같은 색 재선택 해제
- 커서 위치 이미지 삽입, 설명, 확대, 삭제
- 제목·본문·체크·이미지 설명 통합 검색
- 플로팅 버튼, 완드 메뉴, `/memo` 명령
- 기본·윈도우 메모장·현재 실리태번·커스텀 테마
- 제공 웹폰트 14종과 사용자 웹폰트 관리
- PC·태블릿·휴대폰 레이아웃과 가상 키보드 대응

## 저장 구조

확장은 SillyTavern의 공식 `/api/files/upload` 경로를 사용합니다. 운영체제 경로를 직접 쓰지 않습니다.

```text
data/<사용자 핸들>/user/files/
├─ chatssi_memo_index.json
├─ chatssi_memo_index.previous.json
├─ chatssi_memo_owner_<소유자 UUID>.json
├─ chatssi_memo_owner_<소유자 UUID>.previous.json
├─ chatssi_memo_img_<소유자 UUID>_<이미지 UUID>.webp
└─ chatssi_memo_backup_<범위>_<날짜>.json
```

인덱스는 캐릭터 카드의 고유 아바타 파일명 또는 그룹 ID를 불변 소유자 UUID와 연결합니다. 실리태번의 캐릭터 이름 변경 이벤트가 발생하면 연결 키를 함께 갱신하고, 복제·재가져오기로 새 아바타 파일이 만들어지면 별도 소유자를 만듭니다.

이미지는 소유자 JSON에 넣지 않고 개별 파일로 저장합니다. 따라서 글자 하나를 수정할 때 큰 이미지 데이터까지 다시 전송하지 않습니다. 사용하지 않게 된 이미지 파일은 안전을 위해 자동 삭제하지 않습니다.

## v1.x 메모의 안전한 이관

v1.x 메모는 각 채팅 첫 줄의 `chat_metadata.st_private_notes_v1`에 있습니다. v2는 해당 값을 읽기 전용 원본으로 취급합니다.

1. v1.x 메모가 있는 채팅을 엽니다.
2. v2가 기존 메모와 이미지를 새 소유자 파일로 **복사**합니다.
3. 새 파일과 이미지의 해시를 다시 읽어 검증합니다.
4. 이관 기록은 채팅 파일명과 원본 내용 해시로 남깁니다.
5. 원래 채팅 JSONL과 메타데이터는 수정하거나 삭제하지 않습니다.

브랜치에 같은 메모가 복제돼 있어도 동일 내용은 한 번만 보존합니다. 같은 메모 ID인데 내용이 다르면 어느 한쪽도 버리지 않고 `이관 충돌본`으로 추가합니다.

모든 과거 채팅을 한꺼번에 서버에서 훑지 않습니다. 각 채팅을 열었을 때 그 채팅의 기존 메모를 확인해 안전하게 합칩니다.

### 구버전으로 되돌릴 때

v1.3.6은 채팅 메타데이터에 남은 마지막 v1 메모만 표시합니다. v2에서 새로 작성하거나 수정한 공유 메모는 v1.3.6에 나타나지 않으며, 다시 v2로 올리면 그대로 보입니다.

## 기존 채팅 메타데이터 수동 삭제

삭제하지 않아도 동작과 용량 외에는 문제가 없습니다. 원본 보존이 가장 안전하므로 확장에는 자동 삭제 기능이 없습니다.

정말 지우려면 다음 절차를 따르세요.

1. v2의 `전체 메모 백업`과 SillyTavern 전체 사용자 백업을 만듭니다.
2. SillyTavern을 완전히 종료합니다.
3. 대상 `.jsonl` 파일을 별도 위치에 복사해 원본 백업을 만듭니다.
4. UTF-8과 줄바꿈을 보존하는 편집기로 `.jsonl`의 **첫 번째 줄만** 엽니다.
5. 첫 줄 JSON의 `chat_metadata` 안에서 `st_private_notes_v1` 키와 값만 삭제합니다.
6. 첫 줄이 유효한 JSON인지 검사하고, 두 번째 줄부터 파일 끝까지는 백업본과 바이트 단위로 동일한지 확인합니다.
7. SillyTavern을 다시 열어 채팅 메시지와 v2 메모를 확인한 뒤에만 백업본을 정리합니다.

`integrity`, `main_chat`, 다른 확장의 메타데이터 또는 두 번째 줄 이후 채팅 메시지는 건드리면 안 됩니다. 여러 파일을 일괄 치환하는 작업은 권장하지 않습니다.

## 수동 백업과 복원

SillyTavern `확장` → `챗시 노트` 설정에서 사용할 수 있습니다.

- `현재 캐릭터 백업`: 열린 캐릭터 또는 그룹의 메모와 이미지를 하나의 다운로드 파일로 만듭니다.
- `전체 메모 백업`: 모든 소유자의 메모와 이미지를 하나의 다운로드 파일로 만듭니다.
- `현재/전체 내부 스냅샷`: 날짜가 붙은 파일을 `user/files`에 별도로 보존합니다.
- `백업 파일 가져오기`: 체크섬과 이미지 해시를 검사한 뒤 복원합니다.

복원의 기본값은 `안전 병합`입니다. 같은 내용은 중복하지 않고 충돌 내용은 별도 메모로 보존합니다. `현재 내용 교체`는 두 번 확인하며, 어떤 복원이든 시작 전에 내부 안전 스냅샷을 먼저 만듭니다.

다운로드 백업은 SillyTavern이 설치된 디스크 자체가 고장 나도 남길 수 있으므로 내부 스냅샷보다 안전합니다. SillyTavern의 전체 사용자 백업에도 `user/files`가 포함됩니다.

## 동시 편집 보호

SillyTavern의 일반 파일 업로드 API에는 조건부 갱신 기능이 없습니다. v2는 데이터 손실을 막기 위해 캐릭터·그룹별로 한 번에 한 탭 또는 기기만 편집하도록 90초 편집권을 사용합니다.

- 다른 곳에서 편집 중이면 현재 창은 읽기 전용으로 열립니다.
- 필요하면 `이 창에서 편집권 가져오기`를 명시적으로 누를 수 있습니다.
- 편집권 충돌 중 저장되지 않은 내용은 충돌 백업 파일로 다운로드합니다.
- 모든 쓰기는 소유자별 순서대로 실행하고 저장 후 서버 파일을 다시 읽어 검증합니다.

## 설치

### GitHub에서 설치

1. SillyTavern의 `확장` → `확장 설치`를 엽니다.
2. `https://github.com/vatip13-spec/ChatSSi-MeMo`를 입력합니다.
3. 설치 후 SillyTavern을 완전히 새로고침합니다.

### ZIP으로 수동 설치

1. 이전 버전의 `ST-Private-Notes`와 `ChatSSi-MeMo` 폴더가 함께 있다면 둘 다 제거합니다.
2. ZIP 안의 `ChatSSi-MeMo` 폴더를 다음 위치에 넣습니다.

   `SillyTavern/data/default-user/extensions/ChatSSi-MeMo`

   사용자 핸들이 다르면 `default-user` 대신 해당 사용자 폴더를 사용합니다.
3. SillyTavern을 완전히 새로고침합니다.

## 슬래시 커맨드

- `/memo` — 메모장 열기
- `/memo 새 제목` — 새 메모
- `/memo 체크 내용` — 체크 항목 추가
- `/memo 검색 단어` — 공유 메모 검색
- `/memo 닫기` — 메모장 닫기

명령 결과는 빈 문자열이며 채팅이나 AI에게 전송되지 않습니다.

## 이미지 제한

- 입력 파일 최대 15MB
- 긴 변 최대 1280px WebP/JPEG 압축
- 메모 하나당 최대 6장
- 저장 및 백업 시 SHA-256 무결성 검사
