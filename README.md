# ChatSSi MeMo

SillyTavern 채팅별 개인 메모 확장입니다. 메모는 현재 채팅의 `chatMetadata`에만 저장되며 채팅 메시지, 캐릭터 카드, 프롬프트 또는 API 요청에 주입되지 않습니다.

## 주요 기능

- 캐릭터명이 아닌 실제 채팅별 독립 메모
- 여러 개의 스티키 메모 카드
- 카드별 자동 높이 및 수동 세로 크기 조절·저장
- 클릭이나 편집 포커스 없이 수동 높이 메모 내부를 바로 스크롤
- 블록 구분 없이 글·체크리스트·이미지를 섞는 연속 편집
- 현재 줄 체크리스트 전환 및 Enter 연속 입력
- 빈 체크 줄에서 Enter 또는 줄 맨 앞에서 Backspace를 눌러 체크 형식 해제
- 현재 커서 위치에 이미지 삽입 및 Backspace·Delete·× 삭제
- 첨부 이미지 클릭 시 화면 안에 맞춘 원본 팝업 보기
- 부분 형광펜
- 이미지 압축 첨부·드래그 앤 드롭·확대 보기
- 제목·본문·체크리스트·이미지 설명 통합 찾기
- 검색어 강조와 이전·다음 결과 이동
- 플로팅 버튼, 완드 메뉴, 확장 설정 메뉴
- 기본·윈도우 메모장·현재 실리태번·사용자 커스텀 테마
- 커스텀 테마 JSON 내보내기·가져오기
- 제공 웹폰트 14종과 사용자 웹폰트 추가·수정·삭제
- 모든 메모의 글꼴 일괄 변경

## 화면 형태

### PC

- 왼쪽 사이드 패널
- 오른쪽 가장자리를 드래그하여 폭 조절
- 채팅과 메모 동시 조작

### 태블릿 가로

- 왼쪽 사이드 패널
- 눈에 보이는 오른쪽 손잡이를 드래그하여 폭 조절
- 메모장이 열리면 채팅 본문과 입력창을 남은 화면 안에 자동 배치
- 메모장 폭을 바꾸는 동안 채팅 영역도 실시간으로 함께 조정
- 마지막으로 조절한 폭 저장

### 휴대폰 및 태블릿 세로

- 기본 위치는 화면 왼쪽 위
- 메모장이 열린 상태에서도 실리태번 채팅 입력 가능
- 제목 영역을 드래그하여 상하좌우 이동
- 네 모서리의 대각선 손잡이로 원하는 방향에서 가로·세로 크기 동시 조절
- 창의 위치와 크기를 화면 방향별로 저장
- 이동하거나 확대해도 현재 화면 바깥으로 벗어나지 않음

## 설치

### GitHub에서 설치

1. SillyTavern의 `확장` → `확장 설치`를 엽니다.
2. 다음 저장소 주소를 입력합니다.

   `https://github.com/vatip13-spec/ChatSSi-MeMo`

3. 설치가 끝나면 SillyTavern을 완전히 새로고침합니다.

Git으로 설치하면 확장 관리 화면에서 이후 버전을 확인하고 업데이트할 수 있습니다.

### ZIP으로 수동 설치

1. 이전 버전의 `ST-Private-Notes`와 `ChatSSi-MeMo` 폴더가 함께 있다면 둘 다 삭제합니다.
2. ZIP에서 `ChatSSi-MeMo` 폴더를 압축 해제합니다.
3. 다음 위치에 폴더째 넣습니다.

   `SillyTavern/data/default-user/extensions/ChatSSi-MeMo`

   사용자 핸들이 다르면 `default-user` 대신 해당 사용자 폴더를 사용합니다.
4. SillyTavern을 완전히 새로고침합니다.
5. 플로팅 메모 아이콘, 완드 메뉴의 `챗시 노트`, 또는 `/memo` 명령으로 엽니다.

## GitHub 저장소 구조

저장소 루트에 다음 파일을 그대로 올립니다.

```text
ChatSSi-MeMo/
├─ manifest.json
├─ index.js
├─ style.css
├─ icon.png
├─ README.md
├─ LICENSE
└─ .gitignore
```

이후 업데이트에서는 같은 이름의 `index.js`와 `style.css`를 수정하고 `manifest.json`의 버전만 올리면 됩니다. 파일명에 버전 번호를 붙이지 않으므로 이전 파일을 삭제할 필요가 없습니다.

## 슬래시 커맨드

- `/memo` — 메모장 열기
- `/memo 새 제목` — 새 메모 생성
- `/memo 체크 내용` — 선택된 메모에 체크 항목 추가
- `/memo 검색 단어` — 현재 채팅 메모 검색
- `/memo 닫기` — 메모장 닫기

명령 실행 결과는 빈 문자열이며 채팅이나 AI에게 전송되지 않습니다.

## 저장과 이미지

- 메모 데이터는 해당 채팅의 메타데이터에만 저장됩니다.
- 이미지는 긴 변 기준 최대 1280px WebP/JPEG로 압축됩니다.
- 메모 하나당 이미지는 최대 6장, 원본 파일은 15MB 이하로 제한됩니다.
- 이미지가 많으면 채팅 파일 크기도 증가할 수 있습니다.

## 테마

- `기본 테마`: 밝은 스티키 메모 스타일
- `윈도우 메모장 테마`: 흰 편집지와 윈도우 도구 모음 스타일
- `현재 실리태번 테마`: 현재 실리태번 테마 색상 추종
- `사용자 커스텀 테마`: 패널·메모·글자·테두리·강조색·모서리 직접 설정

커스텀 테마는 확장 설정에서 JSON으로 내보내거나 가져올 수 있으며, 메모 내용은 테마 파일에 포함되지 않습니다.

## 폰트
